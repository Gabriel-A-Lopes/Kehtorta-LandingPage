## 📖 About the Project

**Kehtorta** is a landing page developed for a family business specializing in handcrafted pies and pastries. The goal was to create a clean and welcoming digital presence that:

- Reflects the brand's artisanal identity
- Drives customer engagement through social media links
- Provides direct access to WhatsApp for orders
- Connects visitors to the business's online storefront

This project served as a real-world application of front-end development skills using React and component-based architecture.

## ✨ Features

- **Responsive Design** — optimized for both desktop and mobile viewports
- **Social Media Integration** — direct anchor links to the brand's social channels
- **WhatsApp CTA** — quick-access button for customer contact and orders
- **Sales Page Redirect** — link to the external online store
- **Component-based Architecture** — built with reusable React components
- **Accessible UI** — leveraging Chakra UI's built-in accessibility standards

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Gabriel-A-Lopes/Kehtorta-LandingPage.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Kehtorta-LandingPage
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
